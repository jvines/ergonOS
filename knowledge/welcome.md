# Welcome to Ergon

The page your first login opens: what is here, and where
to look for the rest. `ergon welcome` shows it again.

Ergon is a workstation for computational science, and a machine that can
describe itself. Nothing below this part of the page was written in advance:
each section is the output of the command in its title, run as the page was
drawn, so it is what this machine has now rather than what someone once wrote
down. Run those commands yourself whenever you want them again.

Where to look first:

- `ergon --help` — every command, with a line on what each one does;
  `ergon <command> --help` says more about one of them.
- `ergon explain --list` — what this machine knows, by topic;
  `ergon explain <topic>` reads one. Advice written for other desktops is
  often wrong here, so start with these.
- `ergon explain using-ergon` — the day-to-day picture: rollback, backup,
  bundles, sleep, updates, and where the things you make land.
- `ergon doctor` — when something is quietly wrong.
